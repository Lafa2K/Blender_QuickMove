CW Sync Final (Blender Add-on)
[PT-BR]
Um add-on simples para o Blender que permite colar strings de Posição e Rotação (Quaternion) diretamente no painel Item > Transform.

Nota sobre a Rotação:
O script inverte automaticamente o componente W do Quaternion (W * -1), pois o CodeWalker utiliza essa convenção invertida em relação ao Blender. Se a rotação não estiver correta, é provável que o CodeWalker tenha sido atualizado ou mudado seu padrão de exportação.

[EN]
A simple Blender add-on to paste Position and Rotation (Quaternion) strings directly into the Item > Transform panel.

Rotation Note:
this script automatically inverts the W component of the Quaternion (W * -1) because CodeWalker uses this inverted convention compared to Blender. If the rotation is incorrect, it is likely that CodeWalker has been updated or changed its export standard.

Como instalar / How to install
Baixe o arquivo .py. / Download the .py file.

No Blender, vá em Edit > Preferences > Add-ons. / In Blender, go to Edit > Preferences > Add-ons.

Clique em Install e selecione o arquivo. / Click Install and select the file.

Ative o add-on "CW Sync Final". / Enable the "CW Sync Final" add-on.

Como usar / How to use
Abra a Sidebar (tecla N) no Viewport 3D. / Open the Sidebar (N key) in the 3D Viewport.

Vá em Item > Transform > CodeWalker Sync. / Go to Item > Transform > CodeWalker Sync.

Cole os valores e clique em Sincronizar. / Paste the values and click Sincronizar (Sync).
